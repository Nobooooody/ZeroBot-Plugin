# asabaguess 资源包构建工具

`build_pack.py` 将**浅羽猜歌(AsabaGuessingGame)**的原始素材转换为插件可导入的
资源包(zip, 内含 `manifest.json` + `audios/<难度>/<音频>`), 供「浅羽导入歌包」导入.

## 源数据约定

素材目录(默认 `/tmp/opencode/caige/猜歌`, 可用命令行参数指定)应包含:

| 文件/目录 | 说明 |
| --- | --- |
| `说明.txt` | 玩法说明(GBK 编码, 供人工核对) |
| `*.xlsx`  | 官方题库: 每行 = 片段时长 / 歌名 / 来源 / 歌手 / 专辑 |
| `WY-11/`  | 音频片段目录; 文件名编码 `难度-歌手-歌名-出处-片段时长`, 如 `B-鹿乃-心做し-28.mp3` |

难度取自文件名前缀: `A-` 简单 / `B-` 普通 / `C-` 困难 (前缀如 `AAAB-` 归入 A).

## 匹配策略

1. 将文件名与题库行按「歌名最长前缀 + 歌手/出处子串」打分匹配;
2. 简繁/全半角/省略差异导致的未匹配项与题库错字, 以脚本内 `OVERRIDES` 表人工修正
   (如题库把 `妄想税` 误写为 `妄想悦`, 以实际歌名 `妄想税` 为准);
3. 自动校验: 输出「文件名首段歌手 vs 题库歌手」不一致告警, 供人工复核.

## 使用

```bash
python3 build_pack.py /path/to/猜歌素材目录
```

产物:
- 资源包目录 `/tmp/opencode/asaba/resource_pack/`
- 可分发的 zip `/tmp/opencode/asaba/resource_pack.zip`

将 zip 分发到机器人所在机器, 然后让管理员回复:

`浅羽导入歌包 <本地绝对路径或群文件名>`

## 关于题目字段

- `difficulty`: A / B / C
- `title` / `artist` / `source` / `album`: 官方题库值(游戏中的可选答案与判题基准)
- 音频保存为 `audios/<难度>/<原文件名>.mp3`

生成的资源包体积约 46MB(MP3 不再压缩), **不纳入 git 仓库**,
需要时随时用本脚本重新生成.
